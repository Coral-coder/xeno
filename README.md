# xeno
## TestFlight

`.github/workflows/ios-testflight.yml` archives and uploads the iOS app. Put `*u` in a commit
subject on `main` to upload, `*b` to archive only, or run it by hand from Actions. Signing uses
Xcode cloud signing and never revokes certificates.

## Xeno

HVAC/R service app for wireless probes (Fieldpiece Job Link first; NAVAC and others next). No subscriptions.

- `project.yml` — XcodeGen project (bundle ID `com.lightwave.xeno`, iOS 17+). `xcodegen generate` to get `Xeno.xcodeproj`.
- `Xeno/Core` — platform-independent core: refrigerant P/T tables (46 refrigerants, bubble/dew, generated by `scripts/gen_refrigerants.py` from CoolProp), psychrometrics, charging math, vacuum/pressure tests, Fieldpiece broadcast decoder. `swift test` runs its tests on Linux or macOS.
- `Xeno/BLE` — CoreBluetooth scanning (Fieldpiece probes broadcast readings; no pairing), GATT explorer, demo probes.
- Probe Lab / Debug capture in the app record raw broadcasts and "what the display shows" notes, and zip + email them for remote decoding.
- `.github/workflows/ios-screenshots.yml` — simulator build, tests and design screenshots (committed to `screenshots/`) on every `claude/*` push.
